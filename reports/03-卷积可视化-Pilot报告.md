# 卷积可视化课件策划报告（Pilot）

日期 2026-11-12 · 版本 1.1 · concept_id `cnv-001`

面向初高中拓展学习与大学衔接。状态为策划稿，学科审阅和学习效果评价待完成。开发路线采用 Windows Unity Editor 直接 Play，完成全部教学功能后迁移 Android，再接入华为 AR。

## 学生要学会什么

学生通过移动一个带权重的小窗口，观察输入如何变成输出。完成课件后，应能解释滑窗与加权求和，预测不同核的作用，并说明 CNN 中的核可以通过训练学习。

直觉可以概括为“移动窗口，每个位置算一次加权和”。数学卷积还包含核的翻转。二维滤镜演示会同时显示原核、翻转后参与计算的核及各项乘积。CNN 中常用的互相关运算另行标注。[PyTorch Conv2d](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Conv2d.html)

## 学生怎样操作

每个任务都包含“预测 → 操作观察 → 解释”。

| 任务 | 学生操作 | 观察与评价 |
| --- | --- | --- |
| A 移动平均 | 滑动一维窗口，切换 3 点和 5 点平均 | 比较尖峰和平滑结果，解释窗口大小的影响 |
| B 图像滤镜 | 在像素网格上移动 3×3 核，切换模糊、锐化、边缘检测 | 先预测输出，再查看逐项乘积与总和，解释权重如何影响结果 |
| C CNN 机制 | 切换输入，逐层查看预设核和特征图 | 说明特征图与核的关系，区分人工预设权重和训练得到的权重 |

Windows 版通过鼠标点击、拖动、单步和自动播放操作，支持暂停、重置和任务切换。先完成 A、B、C 的完整功能与调试，再适配 Android 触摸。AR 阶段将课件板放置到真实平面，复用相同的计算与教学交互。

## 怎样判断做对了

- 计算结果能够逐项复算，核的方向、边界处理、原始数值与显示颜色一致。
- 同一输入切换核后，学生能说明结果变化。边缘响应中的负值可查看，颜色映射有说明。
- 学生在揭示答案前提交预测，观察后留下解释，重置后可重新尝试。
- CNN 演示标明预设权重的来源与用途，解释训练会调整权重，深层特征取决于模型与训练数据。
- 三个任务在 Windows Editor Play 中均可独立完成，随后验收 Android 触摸与 AR 真机表现。

## 课程定位与依据

当前策划将卷积归为大学先修／衔接内容，用于初高中人工智能拓展。仓库的课标映射提供目录级参考，精确的教材版次、条目和大学课程来源仍需学科审阅。公式可作为进阶展开内容。[知识库映射表](../knowledge-base/04-知识库映射表.md)

教师重点检查“卷积就是模糊”“核越大越好”等误解，并用不同权重和窗口大小组织对比。计算方式及输出边界在实施计划中固定，参考二维离散卷积的定义与 valid 输出规则。[SciPy convolve2d](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.convolve2d.html)

工程任务、数据样例及验收步骤见配套计划。[Unity 实施计划](../plans/卷积-Unity实施计划.md)
