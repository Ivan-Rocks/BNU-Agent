# 知识库映射表（RAG 部分）

日期：2026-11-02
版本：1.0（可用库）
用途：RAG 引擎的第一阶段知识库——公开课标 + 人教版教材目录的"知识点 → 年级/科目"映射，供 `classify_stage` 判定"初高中课内 / 大学先修 / 库外原型"
关联：`02-工作流设计.md` 第四节、`01-选型建议.md`

## 一 目标与原则

- 建立"知识点 → 学段/年级/科目"的映射，供 `classify_stage` 判定概念归属。
- **不追求页码级引用**。证据粒度到"教材某册某章/单元"即可。
- 未核实项一律标 `待核实`，不臆断。
- 各学科详细条目拆分为独立文件，本文件是索引 + schema + 判定示例。

## 四 判定规则（classify_stage 三分类）

| 结论 | 判定依据 | 例子 |
| --- | --- | --- |
| 初高中课内 | 概念名/知识点命中某学科条目的 name 或 note | 凸透镜 → k12-phy-005 |
| 大学先修 | 初高中条目均不命中，且属于大学理工科课程（二期知识库） | 卷积 → 信号与系统 |
| 库外原型 | 初高中与大学均不命中，但可视化/教学价值高 | 汉诺塔 |

**判定纪律**：命中 note 中的关键词 ≠ 一定课内，需人工或规则确认是"该概念的实质"还是"浅层相似"（见卷积示例）。

## 五 判定示例：卷积

1. 检索"卷积" → 207 条中，name/note 均无"卷积"。
2. 检索相似词 → 命中"数列求和"（k12-math-043 数列），但这是"加权求和"的浅层相似，不是卷积本身。
3. 结论 → **初高中课内：否；大学先修：是（信号与系统等，二期知识库覆盖）→ 判定为"大学先修/衔接"**。

这验证了 `02-工作流设计.md` 阶段 2 三分类中"大学先修"分支的判定路径。

## 六 数据源与教材版本约定

- 初中四科：以人教社官网（pep.com.cn）现行目录为准，即"2012/2013 审定"旧版教材目录。
- 高中：以人教 A 版（2019）为准（数学为 A 版；物理/化学/生物为 2019 审定版）。
- **版本风险**：初中 2022 课标对应的"2024 新教材"正逐步启用，章目可能与旧版有差异（如化学 2024 版将"酸和碱""盐 化肥"合并为"常见的酸、碱、盐"）。本库以旧版为准，对齐新版需另行核实。
