## 一 规则

- 每行一个概念；概念内容本身在各自的报告里，这里只做登记与引用，不复制正文。
- 定位三分类：`初高中课内` / `大学先修` / `库外原型`。
- 同一概念可被多门课程复用；课程只引用 concept_id。

## 二 字段

| 字段 | 说明 |
| --- | --- |
| concept_id | 稳定编号 |
| name | 概念名 |
| classification | 定位三分类 |
| report | 报告路径 |
| tags | 可组课标签（初高中 AI / Intro to AI / Intro to Discrete Math…） |
| status | prototype / 已审阅 / 已入课 |
